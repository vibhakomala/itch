# Adjustable mirror-jig dimensional spike

Status: Phase 0 assumptions; **no built prototype or universal camera fit**.

The reference path places a phone/tablet with its screen visible and its front camera aimed through a small tilted mirror at the tabletop mat. Device bezels, front-camera location and field of view vary; all attachments should therefore be reversible and adjustable.

| Parameter                 | Initial experiment range                           |
| ------------------------- | -------------------------------------------------- |
| Base footprint            | 160 × 110 mm provisional                           |
| Camera height above table | 60–120 mm adjustable                               |
| Flat mirror face          | 40 × 50 mm provisional                             |
| Mirror tilt               | 35–55° from horizontal; begin at 45°               |
| Mirror offset from camera | 10–40 mm adjustable                                |
| Workspace                 | 210 × 148 mm landscape                             |
| Mat-to-base gap           | Adjust until all four corner positions are visible |

The diagram illustrates one side-view arrangement, without prescribing optical alignment. Use cardboard/printed support, a small flat mirror, removable attachment and the measured print draft. Record the achieved camera mode, mat coverage, mirror angle and camera offset. Keep the camera unobstructed and the device stable during measurement.

Prototype validation must establish full mat coverage, print scale, mirror inversion, focus/blur, shadows, glare and movement recovery. A working field of view must be measured before converting these assumptions into STEP/STL/CAD fabrication files. The low-single-digit cost target comes from NFR-010; this repository does not yet contain a priced or verified BOM.
