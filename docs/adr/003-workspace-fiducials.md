# ADR-003: Workspace fiducial family

**Status:** Open in Phase 1.

**Context:** Four stable anchors must support homography under supported optics, lighting and print conditions (P1-001–P1-005).

**Decision:** No marker family is selected in Phase 0. The printable layout has labeled placeholder corner marks for dimensional review only.

**Consequences:** The draft mat is not a working automatic-calibration asset. Compare candidate detection rates, footprint, licensing and printability with fixtures before accepting a family.

**Alternatives considered:** Custom corner marks, ArUco-like IDs and AprilTag-like IDs remain candidates.
